# LM_DINO — DINO RUN 1.00

[English](README.md) · [Библиотека Zoom ZDL FX](https://github.com/Leemuzhko/Zoom-ZDL-FX)

Динозавр-раннер по мотивам игры из Chrome, прямо на педали Zoom.
Перепрыгивай кактусы, справляйся с растущей скоростью и побей рекорд своего
пресета — всё одним футсвичем.

<img src="LM_DINO-screen.png" alt="Стартовый экран DINO RUN" width="384" height="256">

## Совместимость

| Педаль | Статус |
| --- | --- |
| **Оригинальная MS-70CDR** | **Протестировано, работает.** |
| **MS-50G / MS-60B** | Возможно, запустится; совместимость пока не проверена. |
| **Семейство G1on / B1on** | **Не работает.** По сообщению автора, вреда педали не наносит. |

Информация о совместимости основана на сообщении автора об аппаратных проверках.
Сборка использует профиль оригинальной MS-70CDR **SYSTEM 2.10**.

## Установка

1. Распакуй **LM_DINO.zip** в папку пользовательских эффектов Zoom Effect Manager.
2. Оставь `LM_DINO.ZDL`, `LM_DINO.json`, `LM_DINO.png` и сопровождающие файлы вместе
   в папке **LM_DINO**.
3. Включи **Читать эффекты из папки** в настройках Zoom Effect Manager, выбери
   родительскую папку пользовательских эффектов и перезапусти Manager после изменения файлов.
4. Установи **DINO RUN** из категории **PedalOperated (11 / 0x0B)**.
5. Добавь игру в пресет и открой её главный экран.

[Инструкция по установке из библиотеки](https://github.com/Leemuzhko/Zoom-ZDL-FX/blob/main/README.ru.md#установка-через-zoom-effect-manager)

## Как играть

| Управление | Действие |
| --- | --- |
| Короткое нажатие футсвича на стартовом экране | Начать игру |
| Короткое нажатие футсвича во время бега | Прыгнуть |
| Короткое нажатие футсвича после столкновения | Начать новую попытку |
| Sound в EDIT | Выключить или включить звуки игры; по умолчанию включены |
| Уйти с игрового экрана | Пауза; возврат продолжает попытку |

Удержание футсвича сохраняет штатную функцию тюнера/tap tempo. Игра использует
короткие нажатия. Игровые нажатия не меняют сохранённое в пресете состояние
On/Off эффекта и не запрашивают сохранение пресета на каждом прыжке.

По мере роста счёта бег ускоряется. Три формы кактусов требуют разного момента
прыжка. Счёт и рекорд отображаются до **99999**.

Входной стереосигнал проходит через эффект; при включённом Sound к нему
добавляются звуки игры. Вне игрового экрана звуки игры отключаются.

## Звук и рекорд

**Sound сохраняется в пресете.** Рекорд относится к текущему пресету и позиции
эффекта. Только новый лучший результат обновляется после окончания попытки;
он сохраняется штатной операцией **Auto Save или ручным Save**. При выключенном
Auto Save сохрани пресет вручную, чтобы оставить новый рекорд или изменённую
настройку Sound.

Уход с игрового экрана ставит текущую попытку на паузу. Повторная загрузка
пресета начинает новую попытку и восстанавливает сохранённые Sound и рекорд.

## Экран и данные пакета

Заголовок **DINO RUN** нарисован жирным системным шрифтом. Во время игры виден
значок звука. Графика учитывает неквадратные пиксели LCD: **3:4 по ширине
к высоте**. Превью выше сохраняет это физическое соотношение пикселей.

| Поле | Значение |
| --- | --- |
| Файл | `LM_DINO.ZDL` |
| Название на экране | `DINO RUN` |
| Версия | `1.00` |
| ID эффекта | `0x33FF` (13311) |
| Категория ZDL / ZEM | `PedalOperated`, GID `0x0B` (11) |
