# Игры

[English](README.md) · [Все проекты](https://github.com/Leemuzhko/Zoom-ZDL-FX)

Игры для педалей Zoom, которые устанавливаются как ZDL-эффекты. Перед выбором
устройства проверь совместимость конкретной игры.

## LM_DINO — DINO RUN 1.00

Динозавр-раннер по мотивам игры из Chrome, прямо на педали Zoom.
Перепрыгивай кактусы нажатием футсвича, справляйся с растущей скоростью
и побей рекорд своего пресета.

<img src="LM_DINO/LM_DINO-screen.png" alt="Стартовый экран DINO RUN" width="384" height="256">

### Совместимость

| Педаль | Установленная прошивка | Статус |
| --- | --- | --- |
| **Оригинальная MS-70CDR** | MS-70CDR | **Протестировано, работает.** |
| **MS-50G / MS-60B** | **Прошивка MS-70CDR** | **Работает.** |
| **MS-50G / MS-60B** | Родная прошивка MS-50G / MS-60B | **Не работает.** |
| **Семейство G1on / B1on** | Родная прошивка | **Не работает.** По сообщению автора, вреда педали не наносит. |

Для этой версии требуется **прошивка MS-70CDR**. Информация о совместимости
основана на сообщении автора об аппаратных проверках от **21.10.2026**.

### Игра и сохранение

- **Короткое нажатие футсвича:** старт, прыжок или новая попытка после столкновения.
- **Sound в EDIT:** выключение и включение игровых звуков; настройка сохраняется в пресете.
- **Уход с игрового экрана:** пауза; возврат продолжает попытку.
- **Рекорд:** хранится отдельно для каждого пресета и позиции эффекта. Новый рекорд
  обновляется после окончания попытки и сохраняется штатным Auto Save или ручным Save.

Удержание футсвича сохраняет штатную функцию тюнера/tap tempo.
Игровые нажатия не меняют сохранённое в пресете состояние On/Off эффекта.

### Установка

Распакуй **LM_DINO.zip** в папку пользовательских эффектов Zoom Effect Manager
и оставь все файлы вместе. Установи **DINO RUN** из категории
**PedalOperated (11 / 0x0B)**. ID эффекта — **0x33FF** (13311), версия — **1.00**.

[Полная инструкция, данные пакета и порядок сохранения](LM_DINO/README.ru.md)
также входят в отдельный архив игры.

Превью учитывает **физический пиксель экрана 3:4**. Изображение для ZEM и карточка
каталога показывают тот же стартовый экран в стандартном формате Manager.

Вдохновлено игрой с динозавром из Chrome. Независимый проект, не связанный
с Google или Zoom Corporation.
