# ZDL effect packages

This directory contains ready-to-install custom effects.

**Target devices:** MS-50G · MS-70G · MS-60B · G1on · G1Xon · B1on.

Each effect lives in its own directory. Keep the complete directory together:
- `.ZDL`
- matching `.json`
- PNG icon/image
- any other accompanying files

Release builds publish every top-level effect directory as its own ZIP so it can be extracted directly into the custom-effects folder used by Zoom Effect Manager.

For installation instructions and release downloads, see the [main README](../README.md).

Not every effect has been hardware-tested on every target device. Custom effects remain experimental; keep backups and test carefully.
