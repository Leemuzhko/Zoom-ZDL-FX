# ZDL project packages

Effects are organized by **type / project / effect package**. Browse the
[project index](../README.md) or Russian [index](../README.ru.md).

Each effect folder keeps its ZDL, JSON and original image together. Single-effect
release ZIP names are preserved. Project ZIPs include their descriptions and
cards; the SYNTHESIS project also includes its separate Windows MIDI controller.
The controller installer is not a pedal effect and is not installed with ZEM.
