SYNTHESIS SYNx2

Русская инструкция ↓

Install and start

For small screens, choose Small in the header's Small / Medium / Large selector. It scales the complete panel without reconnecting MIDI. Startup selects an appropriate size automatically.

  1. Run the SYNTHESIS SYNx2 Windows Setup. Python is included; no separate Python installation is needed.
  2. Launch SYNTHESIS SYNx2 from the Start menu. Connect the original MS-70CDR by USB and put SYNx2 (ID915) or SYN10A (ID914) in slot 1, 2 or 3 of the current patch.
  3. Select the Zoom output and reply ports, slot and MIDI channel. For mouse/PC playing choose PC / screen only. Click Connect, then enable PC Keyboard if desired. Z plays the first C.
  4. Sound comes from the pedal, not the computer. Connect the pedal's audio output, enable an oscillator and set its level. Demo previews commands without MIDI or sound.

Playing from a DAW: install LoopBe1 separately

LoopBe1 is only needed for a virtual MIDI route from your DAW. It is not included in this package. A physical MIDI input or mouse/PC keyboard does not require it.

Official LoopBe1 download

  1. On the official page, find LoopBe1 kernel driver and download setuploopbe1.exe (currently version 1.6). Do not select LoopBe30 or ipMIDI.
  2. Close MIDI applications. In the downloaded file's Properties → Digital Signatures, verify publisher Daniel Schmitt and a valid signature. Run the vendor installer, accept its license if applicable to you, and approve the Windows administrator prompt. Restart if requested.
  3. Open the DAW again. Enable LoopBe Internal MIDI in its MIDI output settings and select it as the MIDI track's output. Set the same channel, usually channel 1, in both applications.
  4. In SYNTHESIS SYNx2 click Refresh, then DAW input, and check that the input is LoopBe Internal MIDI. Keep output/reply assigned to Zoom, not LoopBe. Click Connect.
  5. Play or run a MIDI clip in the DAW. The panel's NOTE and Gate indicators should change. If they change without sound, check the pedal oscillator, level and audio connection.

FL Studio example: Options → MIDI settings → Output: enable LoopBe Internal MIDI and assign an unused Port number. Add a MIDI Out channel and set its Port to that number and Channel to 1. Put the notes on that channel.

If it does not work

  • No LoopBe port: restart the DAW, press Refresh, check the driver installation and reboot if needed.
  • LoopBe is muted: remove any MIDI Thru route feeding LoopBe back into itself, then unmute it in the tray icon. Feedback protection deliberately mutes MIDI loops.
  • Zoom port unavailable: close Zoom Effect Manager or another program holding the same port.
  • Driver signature/certificate error: stop and use the vendor support instructions. Do not disable Windows driver-signature enforcement.

Установка и подключение к DAW

Запуск программы

  1. На небольшом экране выбери Small в селекторе Small / Medium / Large в шапке. Вся панель уменьшается без переподключения MIDI. При запуске подходящий размер выбирается автоматически.
  2. Запусти установщик SYNTHESIS SYNx2. Python уже включён — отдельно устанавливать его не нужно.
  3. Открой программу из меню «Пуск». Подключи оригинальный MS-70CDR по USB. В текущем патче поставь SYNx2 (ID915) или SYN10A (ID914) в слот 1, 2 или 3.
  4. Выбери выход и порт ответов Zoom, слот и MIDI-канал. Для экранной/компьютерной клавиатуры выбери PC / screen only, нажми Connect и включи PC Keyboard. Z играет первую ноту C.
  5. Звук идёт из педали. Подключи её аудиовыход, включи осциллятор и подними уровень. Demo только показывает команды — MIDI и звук не отправляются.

Для DAW: отдельная установка LoopBe1

LoopBe1 создаёт виртуальный MIDI-порт между DAW и программой. В установщик он не включён. Для обычного MIDI-входа и игры мышью/клавиатурой этот драйвер не нужен.

Скачать LoopBe1 с официального сайта

  1. Найди раздел LoopBe1 kernel driver и скачай setuploopbe1.exe (сейчас версия 1.6). Не перепутай с LoopBe30 или ipMIDI.
  2. Закрой MIDI-программы. В свойствах скачанного файла → «Цифровые подписи» проверь действительную подпись Daniel Schmitt. Запусти установщик автора, ознакомься с лицензией, подтверди запрос администратора Windows. Перезагрузи компьютер, если установщик попросит.
  3. Снова открой DAW. В её MIDI-настройках включи выход LoopBe Internal MIDI и назначь его выходом MIDI-дорожки. В DAW и SYNTHESIS SYNx2 выбери одинаковый канал — обычно 1.
  4. В SYNTHESIS SYNx2 нажми Refresh, затем DAW input. Проверь, что вход — LoopBe Internal MIDI. Выход и порт ответов должны оставаться Zoom. Нажми Connect.
  5. Запусти MIDI-клип или сыграй в DAW. NOTE и Gate должны изменяться. Если индикаторы реагируют, но звука нет — проверь осцилляторы, уровни и аудиовыход педали.

Пример FL Studio: Options → MIDI settings → Output: включи LoopBe Internal MIDI и назначь свободный номер Port. Добавь канал MIDI Out, поставь тот же Port и Channel 1. Ноты размещай на этом канале.

Если не работает

  • Порта нет: перезапусти DAW, нажми Refresh, проверь установку драйвера; при необходимости перезагрузи Windows.
  • LoopBe заглушён: убери MIDI Thru, возвращающий сигнал обратно в LoopBe, затем сними Mute через значок драйвера в трее.
  • Zoom недоступен: закрой Zoom Effect Manager и другие программы, занимающие этот порт.
  • Ошибка подписи драйвера: останови установку и обратись к инструкциям автора. Проверку подписей Windows отключать не нужно.

Лицензия: личное некоммерческое использование LoopBe1 бесплатно. Для коммерческого использования после пробного периода требуется лицензия автора. Включение драйвера в чужой пакет требует отдельного разрешения даже для бесплатной программы. Условия автора. Разрешение на включение в этот пакет пока не получено.

Программа и установщик пока не подписаны — Windows может показать предупреждение. Сверяй SHA-256 с отчётом сборки и используй пакет от владельца проекта. Сборка для Windows x64; совместимость Windows 10/11 за пределами проверенного компьютера пока не подтверждена.
